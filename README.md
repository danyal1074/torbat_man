# تربت من

درگاه فارسی و راست‌به‌چپ خدمات شهروندی تربت حیدریه، با ثبت واقعی درخواست و پیوست، پیگیری، کارتابل سازمانی، پاسخ، تاریخچه، اعلان، امتیاز و بازگشایی.

این نسخه **آزمایشی با اجرای محلی و استقرار خصوصی سرور** است. اطلاعات در پایگاه داده ذخیره می‌شود؛ سازمان‌ها، ورود بدون پیامک و اطلاعیه‌های نمونه، آزمایشی‌اند. پرداخت، پیامک و اتصال رسمی سازمان‌ها فعال نیستند.

## اجرای محلی

نیازمندی: Node.js نسخه ۲۲ یا جدیدتر و pnpm نسخه ۹.

```powershell
pnpm install --frozen-lockfile
pnpm db:migrate
pnpm db:seed
pnpm dev
```

- شهروند: http://localhost:5173
- کارتابل و مدیریت: http://localhost:5174/admin
- API: http://127.0.0.1:4000
- سند OpenAPI: http://127.0.0.1:4000/openapi.json

ورود شهروند با یک شماره نمونه انجام می‌شود؛ کد موقت تولیدشده در همان صفحه، با برچسب آزمایشی، نمایش داده می‌شود. شماره نمونه شهروند `09120000001` است. از شماره و اطلاعات واقعی در ارائه عمومی استفاده نکنید. هیچ کد ثابت ورود وجود ندارد.

| حساب نمونه | شماره |
|---|---|
| کارشناس شهرداری | `09130000001` |
| مسئول ارجاع شهرداری | `09130000002` |
| کارشناس آبفا | `09140000001` |
| کارشناس برق | `09150000001` |
| مدیر سامانه | `09100000000` |

نشست شهروند و کارشناس کوکی‌های جدا دارند؛ برای دمو می‌توان دو پروفایل مرورگر یا دو پنجره استفاده کرد. در توسعه، کوکی‌های localhost بین پورت‌ها مشترک‌اند؛ استقرار سازمانی باید دامنه و مرز نشست مشخص داشته باشد.

## داده و تنظیمات

در توسعه، PGlite با ذخیره پایدار در `apps/api/.data/pglite` اجرا می‌شود؛ این موتور PostgreSQL واقعی تعبیه‌شده است، نه آرایه در حافظه یا mock. پیوست‌های خصوصی در `apps/api/storage` ذخیره می‌شوند. برای سرور PostgreSQL، متغیر `DATABASE_URL` را تنظیم کنید.

نمونه تنظیمات در `.env.example` است. آن را به `apps/api/.env` کپی و مقدارها را تنظیم کنید. API فایل `.env` پوشه کاری خودش را می‌خواند؛ Vite کلیدهای خصوصی را نمی‌خواند.

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm test:e2e
pnpm build
```

E2E از Chrome نصب‌شده و دو سرور موقت روی پورت‌های ۴۰۱۰ و ۵۱۸۳ استفاده می‌کند؛ داده و پیوست‌های آزمون از داده توسعه جداست. گزارش HTML در `playwright-report` و تصاویر در `test-results` تولید می‌شوند. اگر Chrome نصب نیست، channel را در `playwright.config.ts` با مرورگر موجود جایگزین کنید.

## مسیرهای اصلی

`/` خانه، `/services` کاتالوگ، `/services/:slug` راهنمای خدمت، `/new` ثبت چندمرحله‌ای، `/requests` پیگیری، `/notifications` اعلان، `/assistant` راهنمای واژه‌محور، `/account` پروفایل و خروجی داده؛ `/admin` کارتابل و `/admin/requests/:id` رسیدگی سازمانی.

اپ شهروندی در build دارای manifest و service worker است. فقط پوسته و دارایی‌های عمومی کش می‌شوند؛ پاسخ API، پرونده خصوصی و تصاویر در کش آفلاین قرار نمی‌گیرند. ارسال درخواست پس از بازگشت اتصال، با اقدام و تأیید کاربر است.

## نسخه نصب‌شده روی سرور رشد

وب و API و PostgreSQL تربت من مستقل از پروژه‌های دیگر نصب شده‌اند. دسترسی خصوصی با `ssh -N -L 4180:127.0.0.1:4180 roshd` و سپس http://localhost:4180 است. پنل در http://localhost:4180/admin قرار دارد. [گزارش استقرار و تأیید همجواری](docs/SERVER_DEPLOYMENT.md) شامل شناسه release و بررسی‌های اجراشده است. دامنه عمومی هنوز فعال نشده است.
