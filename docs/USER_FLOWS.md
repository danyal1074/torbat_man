# جریان‌های کاربری — تربت من

## F1 — ورود
`/welcome` (فقط بار اول) → `/login` → شماره موبایل (ارقام فارسی/عربی/لاتین پذیرفته و نرمال می‌شوند) → کد ۵ رقمی → بازگشت به صفحه مقصد.
- خطا: شماره نامعتبر، کد اشتباه (حداکثر ۵ تلاش)، کد منقضی (۲ دقیقه)، محدودیت ارسال مجدد (۶۰ ثانیه).
- محیط آزمایشی: کد روی صفحه با برچسب «محیط آزمایشی» نمایش داده می‌شود؛ پیامکی ارسال نمی‌شود.

## F2 — گزارش مشکل شهری (شهر‌بین) — حداکثر ۲ لمس تا شروع
1. خانه → «مشکلی در شهر دارم» (لمس ۱) → انتخاب موضوع (لمس ۲) — یا جست‌وجو/دستیار.
2. **شرح**: توضیح کوتاه (اجباری، ≥ ۱۰ نویسه)، تا ۳ عکس اختیاری (فشرده‌سازی و حذف EXIF در مرورگر)، هشدار حریم خصوصی چهره/پلاک.
3. **مکان**: «موقعیت فعلی من» (فقط با اجازه) یا لمس روی نقشه یا نوشتن نشانی؛ محله اختیاری.
4. **بررسی**: پیشنهاد خودکار عنوان/سازمان با برچسب منبع (قواعد یا AI) و دکمه اصلاح؛ گزارش‌های مشابه نزدیک (فقط پیشنهاد)؛ تأیید و ارسال.
5. **ثبت موفق**: کد رهگیری قابل کپی/اشتراک، «مشاهده پرونده»، «ثبت گزارش دیگر».
- پیش‌نویس در هر قدم ذخیره محلی می‌شود؛ با قطع اینترنت فرم از دست نمی‌رود.
- موضوع خطرناک (نشتی گاز، برق‌گرفتگی) → صفحه اضطراری به‌جای فرم.

## F3 — درخواست اداری (میز خدمت)
خانه → «کار اداری دارم» → انتخاب سازمان → انتخاب خدمت → جزئیات (مراحل، مدارک، وضعیت اتصال) → «شروع درخواست» → فرم پویا (از JSON Schema خدمت) → بررسی → ثبت → کد رهگیری.
- خدمت بدون اتصال: صفحه توضیح + راهنما؛ دکمه شروع غیرفعال با دلیل صادقانه.

## F4 — پیگیری
خانه (کارت آخرین درخواست) / اعلان / تب درخواست‌ها → جزئیات → خط زمانی، سازمان مسئول فعلی، پیام‌ها.
- وضعیت «منتظر پاسخ شما» → شهروند پاسخ می‌دهد → پرونده به «در حال رسیدگی» برمی‌گردد.
- وضعیت «رسیدگی‌شده» → امتیاز رضایت (۱ تا ۵) → «بسته‌شده»؛ یا «بازگشایی» با دلیل.
- «ردشده» → امکان اعتراض/بازگشایی با دلیل.

## F5 — کارتابل کارشناس
ورود پنل → داشبورد → کارتابل (فیلتر وضعیت/خدمت/اولویت/جست‌وجو کد رهگیری) → پرونده:
- «برداشتن پرونده» (ارجاع به خودم) یا ارجاع به همکار (مسئول ارجاع/مدیر).
- تغییر وضعیت فقط طبق ماشین حالت (`packages/contracts/src/status.ts`) با دلیل.
- پاسخ عمومی (برای شهروند) یا یادداشت داخلی (فقط کارکنان).
- انتقال به سازمان دیگر با دلیل → تاریخچه ارجاع، کارتابل سازمان مقصد، اعلان به شهروند.

## F6 — اطلاعیه
ویراستار محتوا/مدیر سازمان → اطلاعیه جدید (عنوان، متن، منبع، تاریخ انقضا، اهمیت) → انتشار → نمایش در خانه (مهم‌ترین اطلاعیه معتبر و منقضی‌نشده) و صفحه اطلاعیه‌ها.

## F7 — دستیار
«فشار آب خونه کم شده» → نرمال‌سازی متن → پیشنهاد «افت فشار آب / آب و فاضلاب» با میزان اطمینان و منبع پیشنهاد → «شروع گزارش» (فرم با متن پیش‌پر) یا «خدمت دیگری است» (جست‌وجوی دستی).
