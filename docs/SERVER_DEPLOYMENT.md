## تأیید عدم تغییر همسایه‌ها

- هش تمام فایل‌های Nginx فعال قبل و بعد یکسان بود. Nginx reload یا restart نشد.
- نام، PID، وضعیت و شمار restart همه فرایندهای قبلی PM2 با baseline یکسان بود. هیچ فرمان restart/reload عمومی PM2 اجرا نشد.
- سلامت رشد، قبل و بعد، HTTP 200 بود.
- پورت‌های جدید همگی فقط به loopback متصل‌اند. پورت، داده و تنظیمات پروژه‌های دیگر تغییر نکرد.
- از تصویر PostgreSQL موجود در cache استفاده شد؛ هیچ image/container/volume پروژه دیگر حذف یا بازسازی نشد. Docker restart، prune، تغییر فایروال و نصب global Node/npm انجام نشد.

`scripts/verify-deployment.mjs` از طریق تونل SSH و Chrome واقعی اجرا شد:

۱. ورود آزمایشی با نشست کوکی؛ ۲. ثبت از فرم buildشده؛ ۳. ذخیره در PostgreSQL مستقل؛ ۴. ارجاع کارشناس؛ ۵. پاسخ؛ ۶. تغییر وضعیت و تاریخچه؛ ۷. مشاهده نتیجه شهروند؛ ۸. اعلان. کاتالوگ ۴۷ خدمت دریافت شد و خطای JavaScript مرورگر صفر بود. یک پرونده با متن واضح «آزمون استقرار» به‌عنوان داده نمونه باقی مانده است.

تصاویر و گزارش محلی در `.release/verification` هستند و وارد Git نمی‌شوند. مسیرها و baseline خصوصی سرور در shared نگه‌داری می‌شوند.

## دسترسی

```powershell
ssh -N -L 4180:127.0.0.1:4180 roshd
```

اپ: `http://localhost:4180` — پنل: `http://localhost:4180/admin`.

در زمان نصب، `torbat.digiral.ir` به سروری متفاوت از سرور رشد resolve شد؛ بنابراین دامنه عمومی فعال نشده است. برای انتشار عمومی باید DNS مقصد صحیح، TLS و سیاست دسترسی تنظیم شوند. نسخه فعلی با برچسب demo و OTP نمایشی، صرفاً خصوصی و برای داده ساختگی است.
