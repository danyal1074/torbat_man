# محدودیت‌های نسخه فعلی

این نسخه هسته عملیاتی آزمایشی دارد و معادل انتشار عمومی نهایی نیست.

1. **ادارات و هویت:** شهرداری، آبفا و برق نمونه آزمایشی‌اند. SMS و احراز هویت واقعی متصل نیست. ورود آزمایشی مالکیت شماره را اثبات نمی‌کند و نباید روی اینترنت عمومی برای داده واقعی استفاده شود. تولید با `APP_ENV=production` کد ورود را هرگز نمایش نمی‌دهد و تا اتصال SMS خطای صادقانه می‌دهد.
2. **داده:** تست‌های دیتابیس با PGlite اجرا می‌شوند؛ مسیر اتصال PostgreSQL مستقل موجود است ولی تست روی سرور PostgreSQL مستقل در این محیط اجرا نشده است. backup/restore عملیاتی، تست بار و بازیابی خرابی هنوز لازم‌اند.
3. **هوش مصنوعی:** پیشنهاد موضوع و دستیار از قواعد واژه‌محور استفاده می‌کنند. مدل زبانی، RAG، پردازش تصویر/صوت، ثبت هزینه و تحلیل پیشرفته فعال نیستند؛ وجود تنظیم کلید در محیط به معنی اتصال مدل نیست. تمام پیشنهادها نیازمند تأیید کاربرند.
4. **مکان:** دریافت GPS و مختصات دستی و نشانی کار می‌کند؛ انتخاب نقطه روی نقشه و نقشه لایه‌دار هنوز پیاده نشده‌اند. داده مکانی ساختگی به‌عنوان داده رسمی نمایش داده نمی‌شود.
5. **رسانه:** JPEG، PNG و WebP تا ۵MB پشتیبانی می‌شود؛ ویدئو و صوت فعال نیست. بررسی magic bytes و حذف metadata JPEG وجود دارد، اما decode کامل، حذف تمام metadata PNG/WebP، آنتی‌ویروس و محوسازی خودکار وجود ندارد. پیوست‌ها خصوصی‌اند و لینک امضاشده کوتاه‌عمر دارند؛ لینک تا زمان انقضا قابل اشتراک است.
6. **آفلاین:** متن پیش‌نویس در sessionStorage همان مرورگر حفظ می‌شود، با خروج پاک می‌شود و به‌معنی رمزنگاری محلی نیست. فایل انتخاب‌شده پس از reload باید دوباره انتخاب شود. ارسال خودکار پس‌زمینه نداریم؛ پس از اتصال دوباره کاربر ارسال را تأیید می‌کند. داده حساس را روی دستگاه اشتراکی وارد نکنید.
7. **فازهای بعد:** پرداخت و کیف پول، رزرو نان، حمل‌ونقل زنده، گردشگری، رویداد، push، CMS کامل، SLA، فرم‌ساز مدیریتی، مدیریت نقش و شهر، آمار پیشرفته و APK فعال نیستند. کاتالوگ، مدل‌های توسعه آینده و اولویت‌ها مستند شده‌اند؛ وجود یک عنوان در کاتالوگ به معنی پیاده‌سازی workflow آن نیست.
8. **پنل:** کارتابل، جزئیات، پاسخ/یادداشت داخلی، ارجاع، انتقال سازمانی، وضعیت، تصویر نتیجه و آمار پایه واقعی‌اند. مدیریت مرکزی کامل و کنترل واحدهای داخلی سازمان، فیلترهای پیشرفته و export سازمانی هنوز تکمیل نشده‌اند.
9. **دسترسی:** تفکیک مالک و سازمان در API و تست برقرار است. RBAC ریزدانه برای تمام عملیات و گردش تأیید دسترسی مدیر به اسناد، پیش از استفاده عملیاتی لازم است. اعضای فعال سازمان فعلاً روی پرونده‌های سازمان خود کار می‌کنند.
10. **ظاهر:** لوگو و رفرنس‌های تأییدشده دریافت نشده‌اند. جایگاه متنی فعلی نشان موقت است. آزمون خودکار عرض صفحه جای آزمون سالمندان، screen reader و دستگاه Android واقعی را نمی‌گیرد.
11. **حقوقی:** متن معرفی حریم خصوصی جای سیاست حقوقی نهایی، تعیین دوره نگه‌داری یا مجوز انتشار داده را نمی‌گیرد. مسیر حذف حساب در API وجود دارد، اما در UI عمومی عرضه نشده و بازبینی حقوقی و retention لازم دارد.
12. **استقرار:** build محلی و مسیر حیاتی مرورگر بررسی می‌شوند؛ Docker، HTTPS واقعی، نصب PWA روی گوشی و APK در این محیط تست نشده‌اند. هیچ سایت عمومی، پیامک، پرداخت یا اتصال سازمانی ایجاد نشده است.
